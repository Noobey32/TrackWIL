# TrackWIL - Work-Integrated Learning Management System

Welcome to the TrackWIL project repository! This project is being developed as the Capstone Project for the SPM622 module at CTU Training Solutions.

## About The Project

TrackWIL is a centralized, web-based Work-Integrated Learning (WIL) management application. It is designed to replace the manual, email-based, and PDF-heavy workflow currently used by occupational students at CTU Cape Town to track their workplace logbooks.

The system aims to streamline the submission, verification, and monitoring process by providing role-specific dashboards for:

* **Students:** To record daily WIL activities, complete required documentation, and upload evidence.
* **Workplace Mentors:** To review, verify, and digitally sign off on student submissions via secure token links.
* **WIL Coordinators:** To monitor submission statuses and easily identify missing or outstanding work without manual file audits.
* **Lecturers:** To track overall student performance and progress.
