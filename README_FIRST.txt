TRACKWIL - READ THIS FIRST

TrackWIL is a web application for Work-Integrated Learning (WIL) logbooks, built by Group 3
for SPM622 at CTU Training Solutions, Cape Town Campus. Students add their WIL placements,
log their hours and upload their WIL documents; workplace mentors verify entries from a
one-time link; coordinators and lecturers follow every student's progress on one dashboard.

WHERE TO START
- README.md: overview of the project, how to run the application, demo accounts, group
  members and milestones.
- Week 4 Submission/Group3_Week4.pdf: the latest submission in one PDF.
- 05_Source_Code/trackwil/README.md: setup, demo flow, data storage and testing of the app.

RUNNING THE APPLICATION (Node.js 22.13 or newer)
  cd 05_Source_Code/trackwil
  npm install
  npm run dev
Then open http://localhost:3000 and sign in with a demo account, for example
coordinator@ctucareer.co.za / coord123 or student1@ctucareer.co.za / student123.
